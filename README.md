# 开屏跳过（AdSkipper）

一个**本机运行、不联网**的 Android 小工具：应用启动出现开屏广告时，自动点掉它。

> **先说清楚原理**：开屏广告是目标 App 自己渲染的界面，非 root 环境下**没有任何 App 能"阻止"它加载**。
> 本工具做的是：在广告出现后的几秒内，自动找到并点击"跳过 / 关闭广告 / ×"，
> 实在找不到就按坐标点一下，再不行才用返回键把广告页关掉。
> 效果是"广告一闪而过"，而不是"广告从不加载"。

---

## 一、功能

| 能力 | 说明 |
|---|---|
| 控件识别 | 识别「跳过」「跳过广告」「关闭广告」「Skip」「×」等文字或 contentDescription |
| 三级兜底 | ① 点击识别到的控件 → ② 确认是广告页时按坐标点角落 → ③ 仍无效才返回键 |
| 安全边界 | 兜底动作只在“确认广告页”时触发（识别到跳过控件，或页面类名带 splash/advert 等特征）；普通界面只观察、不盲点 |
| 生效范围 | 默认全部应用；可填包名白名单，只对指定 App 生效 |
| 检测窗口 | 只在应用启动后 N 秒内工作，超时自动停手，避免误触 |
| 动作日志 | 主界面显示最近 12 次动作，方便确认是否生效 |
| 隐私 | **不申请 INTERNET 权限**，无网络能力，不收集任何数据 |

## 二、安装（无需任何开发环境）

### 1. 上传到 GitHub

1. 打开 <https://github.com/new>，新建一个仓库（Public / Private 都可以），名字随意，例如 `adskipper`。
2. 进入仓库，点 **Add file → Upload files**。
3. 把本文件夹里的**所有文件和文件夹**拖进去（注意保留 `.github` 目录），点 **Commit changes**。

> 提示：如果拖拽不方便，可以先在本机把 `AdSkipper` 文件夹解压出来再整体拖入。

### 2. 等待自动打包

1. 点仓库上方的 **Actions** 标签。
2. 会看到一个名为 **Build APK** 的任务在运行，约 3–5 分钟。
3. 等它变成绿色 ✔，点进去，在页面底部 **Artifacts** 里下载 `AdSkipper-apk`。
4. 解压得到 `app-release.apk`。

> 第一次使用 Actions 可能需要点击 "I understand my workflows, go ahead and enable them"。

### 3. 安装到手机

1. 把 `app-release.apk` 传到手机（微信文件传输助手 / 数据线 / 网盘均可）。
2. 点击安装，按提示允许"安装未知来源应用"。
3. 打开 App → 点 **打开无障碍设置** → 在列表里找到 **开屏跳过** → 开启。
   - 部分手机会把入口放在「设置 → 无障碍 → 已下载的服务」。
   - 小米/红米还需在「设置 → 应用设置 → 开屏跳过 → 省电策略」设为"无限制"，防止后台被清理。

## 三、使用建议

- **默认设置先跑一遍**：策略选"再不行则按返回键关闭广告页"，坐标选"右上角"。
- 如果某个 App 的跳过按钮在左下角，把坐标改成"左下角"即可。
- 如果不想让它干预某些 App，把那些 App 的包名填进"生效范围"。
- 主界面"最近动作"里能看到每次都做了什么，没反应说明该 App 的广告页比较特殊。

## 四、项目结构

```
AdSkipper/
├─ app/src/main/
│  ├─ AndroidManifest.xml
│  ├─ java/com/adskip/app/
│  │  ├─ MainActivity.java        设置界面
│  │  ├─ SplashSkipService.java   无障碍服务（核心逻辑）
│  │  ├─ Prefs.java               设置存取
│  │  └─ SkipLog.java             动作日志
│  └─ res/                        布局、字符串、图标
├─ .github/workflows/build.yml    云端自动打包
└─ build.gradle / settings.gradle
```

## 五、自己本地构建（可选）

用 Android Studio（Hedgehog 及以上）打开本目录，等待 Gradle 同步完成，
菜单 **Build → Build Bundle(s)/APK(s) → Build APK(s)** 即可。

命令行方式（需已装 JDK 17 与 Gradle 8.7）：

```bash
gradle assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk
```

## 六、已知限制

1. **无法阻止广告加载**，只能尽快关闭；网络慢时仍可能看到 1–2 秒。
2. 部分 App 使用自绘画面或做了防无障碍处理，控件识别不到；若这类广告页的类名也没有 splash/advert 等特征，本工具不会盲点（避免误触），只能手动跳过。
3. 兜底动作只在确认广告页时触发；若仍发生误关，把策略改成“仅点击可识别的跳过控件”。
4. 摇一摇广告、贴片广告不在本工具处理范围内。
